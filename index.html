스탠다리아: 국경의 수호자

개발자 및 개인정보 문의 담당자: 최성근
패키지 이름: kr.cau.regulaguild

스탠다리아는 기기 안에서 실행되는 오프라인 학습 게임입니다. 게임 진행 데이터는 사용자 기기에 저장되며 개발자 서버로 전송되지 않습니다. 이 방침은 앱의 데이터 처리와 사용자가 별도로 보내는 문의에 적용됩니다.

1. 기기에 저장하는 정보와 목적

게임 실행, 진행 상황 복원, 백업 및 학습 기록 제공을 위해 캐릭터 이름, 외형과 직업, 의뢰 진행 상황, 장비와 능력치, 학습 판단 기록 및 설정을 사용자 기기에 저장합니다. 캐릭터 이름은 실명이 아닌 별명을 사용할 수 있습니다. 개발자는 이 데이터를 원격으로 열람하거나 수집하지 않습니다.

2. 수집·전송·제3자 제공

앱에는 회원가입, 로그인, 광고, 인앱 결제, 사용 분석·추적 SDK 및 개발자 서버 연결 기능이 없습니다. 앱은 게임 데이터, 광고 식별자, 위치, 연락처 등의 정보를 개발자에게 전송하지 않습니다. 개발자가 게임 데이터를 제3자에게 제공하거나 판매하지 않습니다.

3. 사용자가 보내는 문의

사용자가 이메일로 문의하면 답변과 문제 해결을 위해 이메일 주소, 문의 내용 및 사용자가 첨부한 자료를 처리합니다. 문의에 필요한 최소한의 정보만 보내주시고 신분증, 비밀번호 또는 결제정보 등은 보내지 마세요. 문의 정보는 처리 목적이 달성되면 삭제합니다. 관계 법령에 따라 보관이 필요한 경우에는 해당 법령에서 정한 기간에 한해 보관합니다. 이메일 송수신에는 네이버 메일을 사용하므로 해당 서비스의 개인정보 처리 방식도 적용됩니다.

4. 백업·보고서 및 외부 서비스

사용자가 요청하면 Android 시스템 파일 선택기를 통해 백업 파일과 학습 보고서를 내보내거나 사용자가 선택한 백업 파일을 불러옵니다. 내보낸 파일에는 캐릭터 이름과 게임 진행·학습 기록이 포함될 수 있습니다. 클라우드 저장소를 선택하거나 파일을 외부에 공유하는 경우 해당 서비스의 개인정보처리방침이 적용됩니다. 파일의 공유 범위는 사용자가 직접 관리해야 합니다.

앱의 공식 참고자료 링크는 외부 브라우저로 열립니다. 방문하는 사이트에서는 해당 사이트의 정책에 따라 정보를 처리할 수 있습니다. 이 방침을 게시하는 웹사이트의 호스팅 제공자도 접속 과정에서 IP 주소 등 접속 정보를 처리할 수 있으며, 이는 앱이 게임 데이터를 전송하는 것과는 별개입니다.

5. 보관 기간과 삭제 방법

기기에 저장된 게임 데이터는 사용자가 초기화하거나 앱 데이터를 삭제할 때까지 보관됩니다.

  • 게임 진행 초기화: 앱의 ‘모험 설정 → 새 모험 시작’을 이용합니다.
  • 기기에 저장된 앱 데이터 전체 삭제: Android 설정에서 해당 앱의 저장공간으로 이동해 ‘데이터 삭제’를 선택합니다. 기기에 따라 메뉴 이름이 다를 수 있습니다.
  • 앱 삭제: 앱의 내부 저장 데이터가 삭제됩니다. 사용자가 별도로 내보낸 백업이나 보고서는 남을 수 있으므로 저장 위치에서 직접 삭제해야 합니다.

앱은 온라인 계정을 만들지 않으므로 별도 계정 탈퇴 절차는 없습니다. 개발자는 사용자의 기기 데이터를 대신 복구하거나 삭제할 수 없습니다.

6. 권한과 보호 조치

앱은 인터넷, 위치, 연락처, 카메라, 마이크 또는 전체 저장소 접근 권한을 요청하지 않습니다. 파일 입출력은 사용자가 선택한 파일과 위치를 대상으로 시스템 파일 선택기를 통해 수행합니다. 기기에 저장된 앱 데이터는 Android의 앱별 저장 영역에서 관리됩니다. 기기 잠금 설정을 사용하고 내보낸 파일을 안전한 곳에 보관해주세요.

7. 이용자의 권리와 문의

사용자는 기기 설정을 통해 앱 데이터를 삭제할 수 있습니다. 이메일 문의와 관련하여 본인의 정보 열람, 정정 또는 삭제를 요청하려면 아래 연락처로 문의해주세요. 요청 처리에 필요한 범위에서 본인 확인을 요청할 수 있습니다.

앱의 기능이나 데이터 처리 방식이 바뀌면 이 페이지와 앱 내 개인정보 안내를 수정하고 시행일을 표시합니다. 추가적인 개인정보 처리가 필요한 경우에는 관련 법령과 플랫폼 정책에 따라 필요한 안내 및 동의 절차를 마련합니다.
